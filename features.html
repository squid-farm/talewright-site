A story workflow, from draft to play

Write the branches. See the story. Test the play.

Talewright is an open-source engine for text-first RPGs and visual novels. Write in plain-text Talemark, inspect how scenes fit together, play through choices, and share your story.

Open the web player Get started

Inspect and test

See how your story branches

The Author Debugger's Map tab lays out scenes, diverts, and hub offers so you can inspect the shape of a story before and during a playtest.

  • Find the path—and what isn't reachable

    See reachable and unreachable scenes, grouped hub offers, and the conditions that gate a divert or offer.

  • Follow a playtest

    Visited scenes and taken diverts or hub offers highlight in route order as you play, go Back, or go Forward. Preview a selected scene without applying its effects or rolling its checks.

  • Take the map with you

    Export the full layout as SVG or PNG. PNG export has a documented memory bound; oversized maps get a clear recommendation to use SVG.

Availability: the production Map tab is on the current main branch; it has not shipped in the latest downloadable CLI preview yet. The debugger is an authoring tool, not a feature embedded in published player games.

Write

Build a story in plain text

Scenes, dialogue, choices, and conditions live in readable .tale files. Talemark handles RPG checks and story grammar; the VS Code extension helps you write and catch mistakes.

Write branching choices, entry conditions, skill checks, and hub offers. Use stats, skills, items, factions, grammar substitutions, and optional character creation without writing application code.

  • Get the VS Code extension
  • Browse Talemark syntax
  • Follow the first-story tutorial

Play and share

Try the story, then choose how to share it

Play The Lost Relic in a browser, or open a story ZIP to check and play your own work. Players can make a character when a story offers setup choices, keep named saves, and use Back and Forward for undo and redo.

When you're ready to share, send a story ZIP for an existing Talewright player, or publish a standalone web game or desktop app. Players don't need .NET; building those standalone packages requires the .NET 10 SDK and internet access to obtain build dependencies, with additional platform components on some targets. See the publishing guide for details.

  • Open the web player and choose The Lost Relic
  • Test a story
  • Share or publish a story

A pre-1.0 preview

Talewright is still in preview: syntax, save formats, and tools may change without notice, and compatibility is not guaranteed before version 1.0. The VS Code extension is runtime-tested on Linux x64; Windows, macOS, and Linux ARM64 support is provisional. Downloads for the CLI exist for Windows, macOS, and Linux, but only Linux x64 execution has been verified so far.
